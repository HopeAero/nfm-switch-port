Spanish UI sprites for the native port (Need for Madness / Extended)
====================================================================

Rendered 2026-10-09 by running the web port's own code (nfm-master/web/ui-sprites-es.js
spanishSprite / spanishPauseBackground, and web/ext/sprites-es.js spanishLoadingMusic /
spanishStart, lifted verbatim from that module) in headless Chromium 1234 (Playwright),
fed the original GIFs decoded with createImageBitmap, exported with canvas PNG encoding.
Fonts: "Arial Black" italic 900 (system font, Windows) and Adventure (ext/fonts/Adventure.ttf).

Every PNG is RGBA. Pixels that were transparent in the GIF are (0,0,0,0) here, and canvas
text is anti-aliased (partial alpha / blended greys), unlike the 1-bit GIF originals.

Columns: PNG | replaces entry | archive | size (orig -> es) | port variable (game.c loader)
